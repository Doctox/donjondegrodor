# Grodor Phaser Prototype

Prototype Phaser separe pour tester un rebuild de scenes et placements.

## Lancer

```bash
npm install
npm run dev
```

## Parcours

1. Intro avec image d'accueil.
2. Scene geole.
3. Scene donjon 16:9.
4. Grodor affiche dans le donjon.
5. Trois portes cliquables.
6. Grodor marche vers la porte.
7. Un evenement simple met a jour le HUD.
